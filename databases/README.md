# Databases

Docker Compose definitions for relational and NoSQL databases.

## Relational Databases

- **[PostgreSQL](./Postgresql/)** - Open-source relational database with pgAdmin.
- **[MySQL](./MySql/)** - Popular open-source relational database.
- **[MS SQL Server](./MsSql/)** - Microsoft SQL Server (Express, Developer, and Windows editions).
- **[Oracle](./Oracle/)** - Oracle Database Express Edition.

## NoSQL Databases

- **[MongoDB](./Mongodb/)** - Document-oriented NoSQL database with Mongo Express.
- **[Redis](./Redis/)** - In-memory data store with Redis Commander.
- **[Elasticsearch](./Elasticsearch/)** - Distributed search and analytics engine with Kibana.
