# Oracle Database XE

Oracle Database Express Edition container with a preset SID and password.

**Official Sites:**
- [Oracle Database](https://www.oracle.com/database/) | [Container Registry](https://container-registry.oracle.com/)

## Quick start

```bash
docker compose -f docker-compose.yaml up -d
```

## Access

- **Listener:** localhost:9445

## Default credentials

- **SID:** XE
- **Password:** P@ssw0rd

## Notes

- You must accept the Oracle container registry terms before pulling the image.
