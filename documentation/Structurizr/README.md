# Structurizr Lite

Structurizr Lite for authoring and sharing architecture diagrams.

## Quick Start

```bash
docker compose -f docker-compose.yaml up -d
```

## Service

| Service | Port | Notes |
| --- | --- | --- |
| Structurizr Lite | 3001 | Web UI at http://localhost:3001 |

## Notes

- Update the host volume path in `docker-compose.yaml` to point at your Structurizr workspace directory.
