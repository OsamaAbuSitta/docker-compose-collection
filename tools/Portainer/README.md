# Portainer

Portainer provides a web UI for managing Docker environments.

## Quick Start

```bash
docker compose -f docker-compose.yaml up -d
```

## Service

| Service | Port | Notes |
| --- | --- | --- |
| Portainer | 9000 | Web UI at http://localhost:9000 |

## Notes

- You will be prompted to set an admin password on first launch.
