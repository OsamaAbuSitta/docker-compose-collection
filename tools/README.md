# Tools

Docker Compose definitions for development and operations tooling.

## Available Services

- **[Portainer](./Portainer/)** - Docker management UI.
- **[SonarQube](./Sonarqube/)** - Code quality and security analysis.
- **[Verdaccio](./Verdaccio/)** - Private npm registry proxy.
- **[Cloudbeaver](./Cloudbeaver/)** - Web-based database management tool.
- **[SchemaSpy](./Schemaspy/)** - Database documentation generator.
- **[Windows Containers](./Windows/)** - Windows-based container environments.
